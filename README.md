# KingSolrac — Official Website

A free, responsive static website for **KingSolrac**, featuring the **100 Racs** music project and **SytherHub / The Slothsdom** community.

## Publish on GitHub Pages

1. Extract the downloaded ZIP on your computer.
2. Open your GitHub repository: `https://github.com/KingSolrac/KingSolrac.github.io`.
3. Select **Add file → Upload files**.
4. Drag in `index.html`, `styles.css`, `script.js` and `README.md` (not the containing folder). Commit the changes.
5. In the repository, open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**, then **main** and **/(root)**. Save.
7. Wait a few minutes and open `https://kingsolrac.github.io`.

**Important:** `index.html` must be at the top level of the repository, not inside a subfolder.

## Customize

- `index.html` contains all page content, links, and release names.
- `styles.css` contains the design and colors.
- `script.js` handles the mobile menu, active navigation and copyright year.
- Replace sample cover artwork and scenic background images with your own photos and artwork when ready.
- The YouTube, TikTok and other social links are starting guesses based on your public handles. Verify them before sharing your site.
- The video display is a **visual placeholder**, not a working video player. Add a real YouTube embed once you choose a video.
- The design uses some externally hosted Unsplash images and Google Fonts, so these need internet access to load.

## Custom domain (optional)

GitHub Pages hosting is free. If you later purchase a domain, you can configure it in Settings → Pages without paying GitHub for hosting.
